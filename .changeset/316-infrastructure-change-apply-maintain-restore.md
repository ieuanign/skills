infrastructure: four more modes and a completed check. Change takes a request as given — a person's words, an `infra-diagnose` request or one `infra-report` suggestion — and opens one pull request holding the infrastructure-as-code tool's plan and an `## Undo` section, refusing and opening nothing when the machine-readable plan destroys or replaces a data-holding resource; a policy change edits `docs/delivery-policy.md` and the pipeline together, after `delivery-policy` Check passes. Apply runs only from the trunk's current head after the merge and refuses any other ref by name. Maintain, the monthly run, bumps pinned versions and refreshes unedited tool scripts through one change pull request, reports the diff of each edited one, prunes backups past retention and checks certificates and DNS; a major upgrade is held out into its own pull request listing its breaking changes. Restore runs `restore-test.sh` and records a `## Restore` comment on the pinned `Infrastructure reports` issue, creating and pinning it when absent. Check passes only when the pipeline passed on the merge commit, every environment's health check answers and the change can be undone.
