setup-ieuanign-skills: the stacked pull requests reference says what to do with a pull request a rebase empties — close it unmerged with a comment naming the pull request its change now sits in, base the one above it on the one below, then `gh stack rebase` and `gh stack push`, each step beside the reason it comes where it does. The rule file carries the instruction, and its pointer names the new case.
